# JUBELAY — Pakistan Shopify Launch Checklist

## Before you start
1. Create Shopify trial: https://www.shopify.com/free-trial  
2. Store name: **JUBELAY**  
3. Currency: **PKR** · Country: **Pakistan**

## Day 1 — Theme & brand
- [ ] Zip `jubelay-shopify/theme/` and upload under **Online Store → Themes**
- [ ] Publish the JUBELAY theme
- [ ] Upload logo: `jubelay-brand-kit/images/jubelay-logo-mens-womens-primary.png`
- [ ] Confirm colors (already set): Black `#2C2C2C`, Gold `#C9A96E`, Cream `#F5F0EB`
- [ ] Fonts: Playfair Display (headings) + Assistant (body)

## Day 2 — Pages & navigation
Create pages and paste HTML from `store-data/pages/`:
- [ ] About Us (`about-us`)
- [ ] Contact (`contact`)
- [ ] FAQ (`faq`)
- [ ] Shipping & Delivery (`shipping`)
- [ ] Return & Exchange (`returns`)
- [ ] Privacy Policy (`privacy-policy`)
- [ ] Terms & Conditions (`terms`)

Menus:
- [ ] Main menu: Home | Shop | Collections | Best Sellers | New Arrivals | About | Contact
- [ ] Announcement bar already in theme

## Day 3 — Products & collections
- [ ] **Products → Import** → `store-data/products.csv`
- [ ] Add real product photos (4–6 per SKU)
- [ ] Create collections: Instant Hijabs, New Arrivals, Best Sellers, Hijab Accessories, Bundles & Sets
- [ ] Assign products via tags (`instant-hijab`, `accessories`, `bundles`, `best-seller`)

## Day 4 — Payments & shipping (Pakistan)
- [ ] Settings → Payments → **Manual payment methods** → Cash on Delivery
- [ ] Add JazzCash + EasyPaisa (app or manual instructions)
- [ ] Shipping: Free above **Rs. 2,000**; else **Rs. 200**
- [ ] Couriers later: PostEx / Leopards / TCS

## Day 5 — Homepage polish
- [ ] Add hero lifestyle image in theme editor
- [ ] Link Featured Collections blocks to real collections
- [ ] Set WhatsApp number in Theme settings → Social & WhatsApp

## Day 6 — Test & launch
- [ ] Place a test COD order
- [ ] Confirm WhatsApp float opens chat
- [ ] Connect custom domain (`jubelay.pk` or `shopjubelay.com`) when ready
- [ ] Install: WhatsApp chat + Judge.me (reviews)
- [ ] Add Meta Pixel + TikTok Pixel when ads start
