## 🚀 Kaise Use Karein?

1. **Guide padho** → `JUBELAY-SHOPIFY-COMPLETE-GUIDE.md` (sab kuch is mein hai)
2. **Design dekho** → `images/` folder mein 5 pictures
3. **Brand follow karo** → `BRAND-GUIDELINES.md` se colors/fonts set karo
4. **Shopify setup** → Guide ke Step 10 follow karo
5. **Launch!**
